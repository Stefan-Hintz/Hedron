Политика конфиденциальности приложения Hedron

Приложение Hedron не собирает персональные данные.

Приложение Hedron работает в песочнице и имеет очень ограниченный доступ к вашему Mac.

  • Печать
  • Чтение и запись только для файлов, которые вы выбираете
  • Эта справка отображается из локального файла. Исходящий сетевой доступ используется только для показа страниц Википедии и Apple, на которые ведут ссылки из этой справки. Все остальные ссылки открываются в браузере по умолчанию.

  • Нет входящего сетевого доступа
  • Нет доступа к камере
  • Нет доступа к микрофону
  • Нет доступа к USB
  • Нет доступа к Bluetooth
  • Нет доступа к вашим контактам
  • Нет доступа к вашему местоположению
  • Нет доступа к вашему календарю
