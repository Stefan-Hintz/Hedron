Kebijakan Privasi Aplikasi Hedron

Aplikasi Hedron tidak mengumpulkan data pribadi.

Aplikasi Hedron berada dalam sandbox dan memiliki akses yang sangat terbatas ke Mac Anda.

  • Pencetakan
  • Akses baca dan tulis hanya untuk berkas yang Anda pilih
  • Bantuan ini ditampilkan dari file lokal. Akses jaringan keluar hanya digunakan untuk menampilkan halaman Wikipedia dan Apple yang ditautkan dari bantuan ini. Semua tautan lainnya dibuka di browser web bawaan Anda.

  • Tidak ada akses jaringan masuk
  • Tidak ada akses kamera
  • Tidak ada akses mikrofon
  • Tidak ada akses USB
  • Tidak ada akses Bluetooth
  • Tidak ada akses ke kontak Anda
  • Tidak ada akses ke lokasi Anda
  • Tidak ada akses ke kalender Anda
